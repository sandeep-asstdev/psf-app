# PSF Bug Register & Root-Cause Fixes

| Screen / Component | What Happened | Root Cause | Fixed |
| :--- | :--- | :--- | :--- |
| **Demo Seeding** (`scripts/seed_demo.py`) | `NotNullViolationError: null value in column "brand_id" of relation "rating_scales"` | `RatingScale` required a non-null `brand_id` foreign key that was missing during instantiation. | **Yes** |
| **Demo Seeding** (`scripts/seed_demo.py`) | `NotNullViolationError: null value in column "assigned_to_id" of relation "reminders"` | `Reminder` required an explicit assignee `assigned_to_id` in schema which was not set in seed loop. | **Yes** |
| **Playwright Test Runner** | `browserType.launch: spawn UNKNOWN` with bundled `chrome-headless-shell.exe` | Headless-shell binary execution permissions failed on Windows host. Configured `channel: 'chrome'` to use local Chrome. | **Yes** |
| **Home / Advisor Routing** (`HomePage.jsx`, `LoginPage.jsx`) | `403 Forbidden` on `/psf/dashboard` when Service Advisor logs in | `HomePage.jsx` unconditionally requested `/psf/dashboard` (`call.view`). Service Advisors only have `advisor.action`. Added direct redirection to `/advisor` and permission guard. | **Yes** |
| **PSF Queues / Scoping** (`backend/app/core/permissions.py`) | `500 Internal Server Error` in `/psf/queues` when Branch Manager logs in | `apply_data_scope` joined `JobCard` table when it was already joined in `psf_service.py`, throwing duplicate table SQL error. Replaced join with non-colliding subquery `job_card_id.in_(select(JobCard.id).where(...))`. | **Yes** |
| **User Directory Access** (`backend/app/api/v1/endpoints/users.py`) | `403 Forbidden` on `GET /users?limit=100` during master data fetch for CREs and Managers | `GET /users` strictly required `USER_CREATE` or `USER_EDIT`. Regular staff viewing queues/complaints were blocked. Updated permissions to allow `CALL_ALLOCATE`, `COMPLAINT_VIEW`, and `REPORT_VIEW`. | **Yes** |
| **DMS Import Summary** (`backend/app/services/allocation_service.py` & `DataImportPage.jsx`) | Equal split CRE cards not rendering after upload | Summary structure mismatch (`run.summary` stored nested dictionary under `per_cre` instead of flat array). Updated backend to emit both `per_cre` and `assigned_cres` and frontend to parse both safely. | **Yes** |
| **DMS File Upload Race Condition** (`DataImportPage.jsx`) | File upload flagged 100% row errors (`Unknown Branch 'N/A'`) if uploaded immediately before branch masters finished loading | Import submit button was active before `fetchMasters()` completed, resulting in empty string `branch_id`. Added `loadingMasters` guard and disabled submit button until masters resolve. | **Yes** |
